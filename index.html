Feature Engineering

Precomputed Structural Features

Before the first GNN layer even runs, cheap classical graph algorithms compute structural signals that get concatenated into each node's input feature vector X — the GNN then refines, not replaces, these signals.

Same graph, three feature viewstoggle below

PageRank / centrality

Node size ∝ stationary visit probability under random-walk transitions. High-centrality accounts (hubs, mules) surface immediately — before any labeled example is seen.

Connected components

Union-find over the raw graph groups entities into disjoint clusters. A component id is itself a powerful feature: Marcus & Devon's cluster shares an address and device with no legitimate customers in it.

Also common

  • Degree / triangle count — local density, shared-neighbor fraud rings.
  • k-core number — how deeply embedded in a dense subgraph.
  • Louvain community id — soft clustering when components are too coarse.

Summary

      
Key Takeaways for Deployment


      

        

          
          
Heterogeneous & Inductive

          
Combine ownership edges with dynamic flows using inductive GNNs (GraphSAGE/GAT) so unseen entities score instantly.

          
        

        

          
          
Precompute Structural Signals

          
PageRank, connected components, and degree land in X before layer one — cheap signal the GNN then refines.

          
        

        

          
          
Strict Temporal Guardrails

          
Validate exclusively with temporal cutoff splits — random node splits leak future information into training.

          
        

        

          
          
Match Architecture to Time Signal

          
Stateful TGN memory for slow-building patterns; a simple Δt edge feature when per-event recency is enough.

          
        

        

          
          
PU Learning Optimization

          
Replace BCE with nnPU loss to overcome severe unflagged-fraud noise and recover hidden laundering rings.

          
        

        

          
          
Bounded Subgraph Serving

          
Stream in-memory graph engines that sample k-hop subgraphs on-the-fly for real-time scoring, batch for full-ledger sweeps.
